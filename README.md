# ANJAR Portal test app

`ANJAR-Portal-0.3.54.apk` is the Android test build (version 0.3.54, Android versionCode 80, nine languages), built from branch sekretarka-booking-urgent, commit f75047c:
Voice ID, "Answer only my voice", with team voices as an option (up to 5 people, each sets up their own voice in person; checked on the phone, nothing sent);
sign-ins that expire and can be ended (change password, sign out all other devices); web answers for Hungarian businesses, the Book-keeper and the Advisor;
"remember ..." in all nine languages. Also everything from versionCode 79: the Receptionist books callers into free times on the call and puts urgent calls through.
Voice ID, the new account buttons and the new Receptionist switches work once that branch is merged into main (the live server).
It installs as an update over the earlier 0.3.54 test builds (same key, higher versionCode).
It is signed with a test key, not the Play Store key. Share it with testers only.

The live server runs anjar-portal-v2 (switched 28 October 2026).
