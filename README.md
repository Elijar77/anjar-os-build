# ANJAR Portal test app

`ANJAR-Portal-0.3.54.apk` is the Android test build (version 0.3.54, Android versionCode 77, nine languages), built from main commit 01f1f74:
Asystent web answers with sources, Hands-free ("Anjar, …" while the app is open; off until turned on), timers and alarms by voice,
short sign-up ticks with "Show more", Urdu phone calls (server side), security pass.
It installs as an update over the earlier 0.3.54 test builds (same key, higher versionCode).
It is signed with a test key, not the Play Store key. Share it with testers only.

Web answers and Urdu calls need the live server to run anjar-portal-v2 (Render switch pending).

This branch holds only the app file, for the download link.
