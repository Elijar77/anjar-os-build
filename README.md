# ANJAR Portal test app

`ANJAR-Portal-0.3.54.apk` is the Android test build (version 0.3.54, nine languages), built from main commit 73a3470 (voice fix).
It is signed with a test key, not the Play Store key. Install it on your own phone only.

This branch holds only the app file. It can be deleted after installing: `git push origin --delete app-download`.
