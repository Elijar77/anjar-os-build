# ANJAR Portal test app

`ANJAR-Portal-0.3.55.apk` is the Android test build (version 0.3.55, Android versionCode 81, nine languages), built from commit 1e36870
(branch sekretarka-booking-urgent). It is the 0.3.55 release that went live on 28 October 2026, plus: "Erase all data" also ends this
device's sign-in at the cloud, web answers no longer comment on the search results, and the version shows as 0.3.55.
It installs as an update over the earlier test builds (same key, higher versionCode).
It is signed with a test key, not the Play Store key. Share it with testers only.

`ANJAR-Portal-0.3.54.apk` is the earlier test build (versionCode 80), kept for reference.

The live server runs anjar-portal-v2 (switched 28 October 2026).
