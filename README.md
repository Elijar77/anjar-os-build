# ANJAR Portal test app

`ANJAR-Portal-0.3.54.apk` is the Android test build (version 0.3.54, Android versionCode 76, nine languages), built from main commit 0177b41: voice message fix, easier sign-in, Urdu phone calls (server side), lint clean-up.
It installs as an update over the earlier 0.3.54 test build (same key, higher versionCode).
It is signed with a test key, not the Play Store key. Share it with testers only.

This branch holds only the app file, for the download link.
